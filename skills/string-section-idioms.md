# String Section Idioms

## Purpose

Assign idiomatic roles across a string section.

## Use when

- assign idiomatic string section roles

## Do not use when

- when the target ensemble has no string section

## Inputs

- instrument roster and roles
- register, texture, and balance constraints

## Outputs

- instrumentation and texture choices
- candidate part assignments

## Procedure

1. Map range and technical limits.
2. Assign rhythmic and registral roles.
3. Check balance at entrances and releases.

## Hard constraints

- Do not assign an unidiomatic double stop as a default.
- Keep section roles audible through rests and articulation.

## Heuristics

- Use divisi or solo only when the texture needs contrast.
- Let lower strings support rather than mask inner lines.

## Validation status

P1 has no implemented engine validator for this card. Treat every result as advisory until P2 provides named operations and validators; do not describe an unimplemented check as performed.

## Failure modes

- Overloading one register with every section.
- Ignoring bow or position feasibility in the part.

## Examples

- A low-string pedal beneath a solo violin.
- A divisi texture with a clear registral plan.
